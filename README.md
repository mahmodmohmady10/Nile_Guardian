# حارس النيل: رحلة الأمين (`nile_guardian_rpg`)

لعبة أدوار ثنائية الأبعاد بالعربية، بطلها «الأمين» ورفاقه من الحياة البرية السودانية.
تعمل دون إنترنت على Windows 10/11، وتُبنى بـ Python و pygame-ce.

> الحالة الحالية: **M2 — الخريطة والحركة والاصطدام** (منفذ، ينتظر اختبار النافذة). M1 مكتملة (وسم `m1`).

## حالة المراحل

| المرحلة | الحالة | ملاحظات |
|---|---|---|
| التحليل والمتطلبات والتصميم (v1.1) | معتمد | الوثيقة خارج المستودع حالياً، انظر «المتبقي» |
| M0: التهيئة + Spike العربية | مكتمل (وسم `m0`) | اختبره المطوّر: pytest (3 نجحت) وruff (نظيف) |
| M1: النواة ومكدس المشاهد | مكتمل (وسم `m1`) | pytest: 21 ناجحاً، ruff نظيف، النافذة تعمل |
| M2: الخريطة والحركة والاصطدام | **منفذ، ينتظر اختبار النافذة** | انظر «ما تم اختباره في M2» |
| M1 إلى M6 | مخطط | لم يبدأ |

## تشغيل اللعبة

```bat
python -m src.main
```

في القائمة: الأسهم أو W/S للتنقل، Enter أو Space للتأكيد، Esc للرجوع من الشاشة المؤقتة.

## التثبيت (Windows)

```bat
py -3.10 -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
```

مهم: لا تثبّت `pygame` التقليدية مع `pygame-ce`. إن كانت مثبتة نفّذ أولاً `pip uninstall pygame`.

## Spike العربية (جزء من معيار قبول M0)

1. حمّل خطاً عربياً مفتوح الترخيص (Tajawal أو Cairo من Google Fonts، ترخيص OFL)
   وضعه في `assets/fonts/` مع ملف الترخيص. يُفضَّل ملف ثابت (Static) لا متغير (Variable).
2. شغّل:

```bat
python tools/arabic_spike.py --font assets/fonts/Tajawal-Regular.ttf
```

3. افتح `spike_output/comparison.png` وافحص بعينك: اتصال الحروف، الاتجاه من اليمين لليسار،
   مواضع التشكيل، وسطر «الحيوية: 80/100 — HP».
4. سجّل في هذا الملف: الطريقة المعتمدة (A: reshaper+bidi أو B: المدمج) وأرقام الأداء.

## ما تم اختباره وما لم يُختبر (M0)

| البند | الحالة |
|---|---|
| صياغة الملفات (`py_compile`) | مختبر في بيئة الإنشاء |
| اختبارات `tests/test_smoke.py` (الهيكل + حارس عزل pygame) | مختبرة بمشغّل بسيط خارج pytest، لأن pytest غير مثبت في بيئة الإنشاء |
| `pytest` و `ruff check` الفعليان | **غير مختبرين**، شغّلهما عندك |
| تثبيت الحزم من `requirements.txt` | **غير مختبر** (لا إنترنت في بيئة الإنشاء)، أرقام الإصدارات حدود دنيا غير محققة |
| `tools/arabic_spike.py` | **غير مشغّل**: pygame-ce غير مثبت هنا، والفحص البصري مطلوب منك |

## المتبقي في M0

- تشغيل `pytest` و `ruff check` وإصلاح أي ملاحظات.
- تصدير وثيقة التصميم v1.1 إلى `docs/SYSTEM_DESIGN.md`.
- أول `git commit` ثم الوسم `m0` كنسخة مستقرة.

## القرارات التقنية

- ADR-001: عرض العربية بالمحرك المدمج (B)، والمقاطع اللاتينية والأرقام بعرض منفصل. انظر `docs/DECISIONS.md`.

## الأخطاء والقيود المعروفة

- طريقة `arabic-reshaper` تُخرج أشكالاً غير موجودة في Tajawal-Regular.ttf فتظهر مربعات (انظر ADR-001). لم تعد المسار الافتراضي.
- لا يوجد خط في `assets/fonts/` بعد.
