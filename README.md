# حارس النيل: رحلة الأمين

لعبة أدوار ثنائية الأبعاد باللغة العربية، من تطوير mahmoud mohamedy، بمساعدة Claude. تقع أحداثها في قرية على ضفاف النيل ومحمية الدندر في السودان.

> **الحالة:** نسخة تجريبية عامة (`v1.3.0-beta`). اللعبة تعمل، لكنها لا تزال قيد التوازن والتطوير. ملاحظاتك مرحب بها.

## ما الذي ستجده في اللعبة

- **رحلة الأمين:** تبدأ في القرية، وتتعرف على العم الطيب، وتحصل على صقر الجديان رفيقاً لك.
- **حيوانات السافانا:** الغزال، والتمساح، والذئب، والنمر، والأسد، بصفات مختلفة لكل منها.
- **معارك دور بدور:** تبديل الرفاق، واصطياد الحيوانات الضعيفة، واستخدام العناصر والمهارات.
- **الخبرة والمستويات:** كل فوز يمنح الفريق خبرة، وعند المستويات 3 و5 و7 تفتح مهارات جديدة.
- **المستشفى والمتجر:** ترقية الحيوانات دائماً في المستشفى، وشراء العناصر من التاجر بالنقود.
- **الحفظ:** ثلاث خانات حفظ يدوي، وخانة تلقائية تُحدَّث عند دخول خريطة جديدة.

## التثبيت والتشغيل

### الطريقة الأولى: الملف التنفيذي (الأسهل)
1. حمّل `NileGuardian.exe` من صفحة **Releases**.
2. شغّله. نافذة الطرفية تبقى مفتوحة في هذه النسخة لعرض الأخطاء إن حدثت.

### الطريقة الثانية: من المصدر (للمطورين)
يتطلب Python 3.10 أو أحدث، وWindows 10/11.

```bat
py -3.10 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m src.main
```

يحتاج التشغيل إلى ملف الخط `Tajawal-Regular.ttf` داخل `assets/fonts/`.

## التحكم

| المفتاح | الفعل |
|---|---|
| الأسهم أو W/A/S/D | الحركة والتنقل في القوائم |
| Enter أو Space | التأكيد، والتفاعل مع الشخصيات، وتقدّم الحوار |
| Esc | الرجوع، وتخطي الحوار، والعودة إلى القائمة الرئيسية من العالم |
